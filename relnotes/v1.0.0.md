# VPET v1.0.0

I am excited to announce the first stable release of **VIPET – Visual & Interactive Performance Evaluation Tool**.

## ✨ Highlights

- **Visual Queueing Network Editor**  
  Design and modify queueing networks through an intuitive graphical interface.

- **Analytical Evaluation of Performance Measures**  
  Includes support for Jackson and Gordon–Newell models.

- **Discrete-Event Simulation (DES)**  
  Run automated or step-by-step simulations directly within the application.

- **What-If Analysis**  
  Experiment with different configurations and immediately see their impact on performance.

## 📦 Installation

- **Windows**: Download and install the `.msi` package.
- **Linux**: Install the `.deb` package or use the portable AppImage.

- This is the first production-ready release. Future minor versions may introduce changes to APIs and configuration formats.
