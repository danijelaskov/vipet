# VIPET v1.0.2

A bug-fix and maintenance release of **VIPET – Visual & Interactive Performance Evaluation Tool**.

## 🐞 Fixes

- **Excel export of performance measures**  
  Exporting performance measures to `.xlsx` or `.xls` files no longer fails with an error.

## 🔒 Security & Dependencies

- **Updated dependencies with known vulnerabilities**  
  Log4j, JavaFX and several transitive libraries were updated to versions that fix known security issues.
- **JavaFX 21.0.13**  
  The bundled JavaFX runtime was updated to the latest 21 LTS patch release.

## 📦 Installation

- **Windows**: Download and install the `.msi` package.
- **Linux**: Install the `.deb` package or use the portable AppImage.

## ⚠️ Notes

- Please report bugs and suggestions via the [issue tracker](https://github.com/danijelaskov/vipet/issues).
