# VIPET v1.1.0

A feature release of **VIPET – Visual & Interactive Performance Evaluation Tool**.

## ✨ Highlights

- **Simplified Buzen's algorithm for closed networks**  
  When every service center has a single server and exponential service time, the analysis uses the simplified recurrence `G_n(k) = G_{n-1}(k) + x_n · G_n(k-1)`, where `x_n = v_n / μ_n`, instead of the general algorithm.
- **Clearer step-by-step analysis**  
  For such networks the analysis view shows the `x` values in place of the `F` table, and hovering a `G` cell highlights the values it is calculated from and shows the recurrence.
- **Symbolic tooltips in the Gordon-Newell analysis**  
  The `F` and `x` tooltips now show the formula using symbols, such as `x_n = v_n / μ_n`, matching the `G` tooltips, instead of substituting the numeric values.

## 📦 Installation

- **Windows**: Download and install the `.msi` package.
- **Linux**: Install the `.deb` package or use the portable AppImage.
