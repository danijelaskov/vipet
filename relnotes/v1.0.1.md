# VIPET v1.0.1

A bug-fix release of **VIPET – Visual & Interactive Performance Evaluation Tool**.

## 🐞 Fixes

- **Gordon–Newell analysis of networks with multi-server service centers**  
  Re-analyzing a closed network after modifying it no longer fails with an error or yields stale performance
  measures and state probabilities.

## 📦 Installation

- **Windows**: Download and install the `.msi` package.
- **Linux**: Install the `.deb` package or use the portable AppImage.

- Please report bugs and suggestions via the [issue tracker](https://github.com/danijelaskov/vipet/issues).
